# Example data files for Flood Tool

These files are provided as examples for use with the Flood Tool. They include examples of the basic postcode data features you can assume will be available, rainfall data, river data, and tide data.

Data is taken from the Environment Agency Open Data API, the UK Office of National Statistics, and other public sources. See the [LICENSES.txt](LICENSES.txt) file in the resources directory for details of data sources and licences.
